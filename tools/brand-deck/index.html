This brand guide is the single source of truth for FastBridge visual identity. Use it whenever you design or communicate across the website, product UI, marketing, and partner materials — so every touchpoint feels consistent, clear, and ready to publish.

Brand Guidelines
Logo
03

Logo

The FastBridge mark pairs a geometric icon with a lowercase wordmark. Use the white version on dark backgrounds and the black version on light surfaces.

Always scale proportionally. Minimum digital height for the full lockup is 32 px. Do not stretch, recolour, or rearrange the icon and wordmark.

Colours
04

Colours

FastBridge uses a restrained neutral palette with a single accent blue. Apply CSS custom properties in code to keep surfaces, text, and borders consistent.

Hero and FAQ sections use dedicated dark scrim values layered over photography and gradients.
